# Input Files Organization Summary

## Essential Configuration Files

### MakeMieTable (Phase Function Generation)
**Keep these files:**
- `mie_table_cloud.nml` - Water cloud droplets (γ-distribution, α=7.0)
- `rural_aerosol_mie.nml` - Rural/continental aerosols (absorbing, realistic)
- `aerosol_mie.nml` - Dust aerosols (less absorbing)
- `absorbing_aerosol_mie.nml` - Highly absorbing aerosols (black carbon-like)

**Research configurations:**
- `mie_table_research.nml` - Research-specific configuration

### MonteCarloDriver (Simulation Control)
**Essential files:**
- `MonteCarloDriver.nml` - Standard configuration template
- `MonteCarloDriver_research.nml` - Optimized for systematic studies
- `rural_aerosol_proper.nml` - Rural aerosol simulation (τ≈0.2)
- `thin_cloud.nml` - Thin cloud simulation (τ≈0.2)

**Testing configurations:**
- `MonteCarloDriver_small.nml` - Quick tests (fewer photons)
- `minimal_aerosol_test.nml` - Minimal test case
- `MonteCarloDriver_clear_sky.nml` - Clear sky baseline

**Special purpose:**
- `MonteCarloDriver_diffuse.nml` - Direct/diffuse separation studies

### PhysicalPropertiesToDomain (Physical Properties)
**Domain text files:**
- `cloud.txt` - Standard cloud profile
- `thin_cloud.txt` - Thin cloud (τ≈0.2)
- `rural_aerosol_proper.txt` - Rural aerosol profile
- `clear_sky.txt` - Clear sky (no particles)

**Domain configuration files:**
- `cloud_domain.nml` - Cloud domain configuration
- `thin_cloud_domain.nml` - Thin cloud domain
- `rural_aerosol_proper_domain.nml` - Rural aerosol domain
- `clear_sky_domain.nml` - Clear sky domain

**Research files:**
- `cloud_research.txt` - Research cloud configuration
- `cloud_domain_research.nml` - Research domain configuration

## Recommended Workflow Configurations

### 1. Research-Ready Setups

#### Thin Cloud vs Rural Aerosol Comparison (τ≈0.2)
```bash
# Phase function tables
MakeMieTable < Input/MakeMieTable/mie_table_cloud.nml
MakeMieTable < Input/MakeMieTable/rural_aerosol_mie.nml

# Domain files  
PhysicalPropertiesToDomain < Input/PhysicalPropertiesToDomain/thin_cloud_domain.nml
PhysicalPropertiesToDomain < Input/PhysicalPropertiesToDomain/rural_aerosol_proper_domain.nml

# Simulations
MonteCarloDriver < Input/MonteCarloDriver/thin_cloud.nml
MonteCarloDriver < Input/MonteCarloDriver/rural_aerosol_proper.nml
```

#### Absorbing vs Non-absorbing Aerosols
```bash
# Phase function tables
MakeMieTable < Input/MakeMieTable/aerosol_mie.nml          # Dust (low absorption)
MakeMieTable < Input/MakeMieTable/absorbing_aerosol_mie.nml # Black carbon (high absorption)
```

### 2. Quick Testing Setup
```bash
# Use small photon counts for fast testing
MonteCarloDriver < Input/MonteCarloDriver/MonteCarloDriver_small.nml
```

### 3. High-Precision Research
```bash
# Use research configuration with high photon counts
MonteCarloDriver < Input/MonteCarloDriver/MonteCarloDriver_research.nml
```

## Parameter Customization Quick Guide

### Optical Depth Control
**Clouds:** Adjust mass concentration in `.txt` files
- τ≈0.1: ~0.005 g/m³
- τ≈0.2: ~0.009 g/m³  
- τ≈0.5: ~0.025 g/m³

**Aerosols:** Adjust mass concentration in `.txt` files
- τ≈0.1: ~0.0005 g/m³
- τ≈0.2: ~0.001 g/m³
- τ≈0.5: ~0.0025 g/m³

### Solar Zenith Angle
Modify `solarMu` in MonteCarloDriver files:
- 0°: solarMu = 1.000
- 30°: solarMu = 0.866  
- 45°: solarMu = 0.707
- 60°: solarMu = 0.500
- 75°: solarMu = 0.259
- 85°: solarMu = 0.087

### Simulation Precision
**Quick tests:**
```fortran
numPhotonsPerBatch = 100
numBatches = 10        ! Total: 1,000 photons
```

**Production runs:**
```fortran
numPhotonsPerBatch = 1000  
numBatches = 1000      ! Total: 1,000,000 photons
```
